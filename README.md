# Number Guessing Game

A Python CLI game where the player tries to guess a randomly generated number within limited attempts.

## Features
- Random number generation
- Hint system
- Attempt tracking
- Input validation
- Loop for repeated play
- Reusable game function  


## Concepts Used
- Variables
- Input/output
- Conditionals
- Looping statements
- Exception handling
- Uses Functions
- State Tracking 
- Random values

## Run

```bash
python3 main.py
```
